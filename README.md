# Rush & Deliver

A 3D delivery game that runs in the browser. Ride a scooter around town, pick up orders from cafés and deliver them before time runs out to earn money.

## Features
- 3D city with GLB models (buildings, cafés, houses, police car, scooter)
- HUD showing the current order, distance, timer and wallet
- No build step: plain HTML + Three.js

## Tech stack
JavaScript · Three.js · GLTFLoader · WebGL

## Run
Serve the folder with any static server, for example:
```bash
npx serve .
```
Then open the URL it prints.
